# Cossel (Cosmetics Selection)
Индивидуальная подборка косметических средств.

## О проекте
Сайт предназначен для помощи пользователям в выборе декоративных косметических средств с учетом индивидуальных особенностей и предпочтений. Пользователь сможет указать тип кожи, категорию товара, непереносимости некоторых компонентов и другие параметры, после чего система предложит наиболее подходящие косметические средства.

## Технологии

- React 
- TypeScript
- Vite
- React Router
- json server
- Fetch API
- CSS

## Как запустить
1. Установить зависимости: npm install
2. Запустить сервер API в отдельном терминале: npx json-server db.json --port 3001
3. Запустить React-приложение в другом терминале: npm run dev
4. Открыть адрес, указанный Vite в терминале (http://localhost:5173).


## Реализованные возможности
- Просмотр каталога косметических средств
- Поиск по названию и бренду, фильтрация по категории без перезагрузки страницы
- Страница товара с брендом, категорией, описанием и составом
- Анкета подбора из 3 шагов (категория, особенности кожи, непереносимые компоненты)
- Избранное с сохранением в localStorage
- Режим администратора: добавление, редактирование и удаление товаров
- Проверка обязательных полей в формах до отправки запроса
- Состояния загрузки, ошибки и пустого результата
